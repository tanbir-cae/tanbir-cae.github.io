# Security rules

- Never commit Supabase service_role/secret keys.
- Never commit passwords, recovery codes, or private API keys.
- Keep the repository public only for public website code/assets.
- Use one admin account with a strong unique password and TOTP MFA.
- Only publish files intended for public viewing.


## Public project files

Files uploaded to the public bucket are intentionally accessible to visitors. Use the private bucket only for material that should not be public. Never commit Supabase secret/service-role keys to GitHub.
